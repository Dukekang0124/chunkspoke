# ASR-209 · 音素通道阈值定标

> 目的：给「判卷第三通道（音素编辑距离）」一个**可复现、不拍脑袋**的阈值。
> 复现：`flutter test test/phonetics_test.dart`（失败即说明词表/规则或阈值被改动后不再自洽）。

## 一 方法

1. 构造两组样本：
   - **应放行**：同音/近音但拼写不同的词对（ASR 小模型的典型转写漂移），判卷必须判对；
   - **应拒绝**：元音或辅音真正不同、语义不同的最小对立对（minimal pairs），判卷必须拒绝。
2. 用 `phonemeRatio(a,b) = 1 − 编辑距离 / 较长音素串长度` 计算每一对（`lib/services/phonetics.dart`）。
3. 取「应放行组的最低值」与「应拒绝组的最高值」；阈值必须严格落在两者之间，
   并记录余量。**若两组重叠，说明规则层不够用，必须补词表/规则，而不是挪阈值。**

## 三 阈值

```
passMin = 1.000   rejectMax = 0.750
kPhonRatio = 0.85 = rejectMax + 0.10（拒绝侧余量），passMin − 0.15（放行侧余量）
```

- 为什么不是 0.75：`rejectMax` 等于 0.75，取等号会把 `snack/snake` 这类
  「错一个元音」真错词放行（`test/speech_match_test.dart` 已钉死必须拒绝）。
- 为什么不是 0.95：留 0.10 给规则层的粗音素误差（弱读、连读、词尾变化），
  但 0.90 以上会开始吞掉 `thin/think`（0.75）之外的边界词，收益不足以抵风险。
- 独立验证：`snack/snake` = 0.750 < 0.85 → 仍判错；`right/write` = 1.000 → 判对。

## 四 维护规则

1. 新增同音样本时，先跑测试看两组是否仍无重叠；有重叠 → 补 `_exceptions` 或修规则，
   **禁止下调阈值**。
2. 规则层（g2p）改动后必须重跑本表并把新数字更新到本文档与 `phonetics_test.dart` 的输出断言。
3. 已知边界（本通道不覆盖）：
   - 整词丢失（识别完全没输出该词）→ 归 B 层（换模型）；
   - 多词弱读（wanna / gonna / hafta）→ 归归一化折叠层 `expandSpokenTokens`；
   - 连读导致的词边界重切（a napple / an apple）→ 当前不处理，留给 B 层。
