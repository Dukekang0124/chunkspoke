## 一 能力边界（按指令 §五）

只用 GLM-4-Flash 做两件事，别的都不许它碰：

1. **模糊带兜底**：判卷层给出 `band='band'`（差一点）时，把「目标句 + 识别文本」
   交给云端判一次「用户说的是不是这句」；云端只允许把 band 提升为通过或维持失败，
   **不允许**把已经命中的句子判成失败（避免云端把对的洗成错的）。
2. **自由造句语义点评**：⑤/⑥ 自由造句已判「用上了词块」之后，给一句中文点评
   （语法/地道程度），**不参与是否掌握的记账**。

不做什么：不接云端 ASR（那是 L2/ASR-188 的路）、不做口语打分、不替换本地判定。

## 二 开关与密钥（红线）

- 默认**关**。设置页一条独立开关「联网评判（会把你要读的句子发给模型服务商）」。
- 只有开关开 **且** 用户已自备 Key（GLM 或自定义 OpenAI 兼容端点，走现有
  `llm_config` + Android Keystore 存储）才发请求；**包内零密钥**，构建期不注入。
- 开关旁必须写隐私说明：发送内容 = 目标英文句 + 识别文本（不上传录音音频、
  不上传学习数据）；关掉后不再有任何请求。
- 无 Key / 无网 / 超时（≤5s）→ 直接按本地结论走，UI 不报错、不转圈卡流程。
