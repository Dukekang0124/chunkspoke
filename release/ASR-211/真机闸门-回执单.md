## 一、装包与三查（升到 1.8.3 后）

| 步 | 做什么 | 看到什么算对 |
|----|--------|--------------|
| 1 | 更新弹窗 → 安装 1.8.3/4083 | 设置→关于 或 系统设置里显示 **1.8.3**；不是 1.8.2 |
| 2 | 打开「今日」→ 咖啡馆（Café）那张卡 | 卡上计数与地图一致；点进去**不再出现**「台账 21/25、上面写第 10 块」这种两回事 |
| 3 | 有跳块的模块（前面欠着、后面已掌握）看「接着上次练」 | 那行写 **第 X 块待通过 · 已掌握 N/M**（两个数同时出现），并且下面多一个 **补练未通过块（N）** 按钮 |
| 4 | 设置 → 诊断 → 跑一次自检 → 导出/发回归档文件 | 「进度完整性」每行出现 `台账 … · 渲染「…」`；有 **孤儿行** 行；红名单为 0 或明确列出哪几个模块 |

诊断导出的孤儿行数字直接决定一件事：**要不要做词块 id 迁移表**。孤儿=0 就不做；有已掌握的孤儿，下一版做迁移表。这条不用你判断，把文件发回来即可。

## 二、两案各三遍（判卷修复的实测）

| 案 | 目标句 | 怎么念 | 看到什么算对 |
|----|--------|--------|--------------|
| 案 1 | `I'd like the main course, please.` | 正常语速念，允许把 I'd 念成 I would | 反馈是 **差一点（可再读一遍，不扣分）**，不是「判错」。提示里出现 man→main 这类按发音判对的说明 |
| 案 2 | `Hello there, my friend.` | 正常念 | 若识别只剩 `O` → 仍判错是**对的**（这是识别层丢词，判卷层不管）。要救它得靠增强识别包：先在设置里把「增强识别包」下载好，再念一遍看是否给到 hello |

两案各念 3 遍，每遍截图（反馈条 + 识别文本）。案 2 请给两组：未下增强包 / 已下增强包各 3 遍。

## 三、20 句真人麦克风评测集（今后换不换引擎以它为准）

句子清单：`release/ASR-211/评测集-20句.json`（全部是 App 现有课程原句，含 4 句撇号缩合、2 句数词、6 句弱读连读）。

录法（怎么省事怎么来，一条原则：**要真人的声音，不要手机合成的**）：

1. 在 App 里找到对应句子（S0 生存包 13 句、A 问候 2 句、B 点单 5 句），点跟读，念完；
2. 用「分享录音」把这条录音发出来（一次发一条，发到你自己的微信文件传输助手即可）；
3. 20 条收齐后一起转给我；命名里能看出句子号最好（`sv_s01`、`b_s07` 这种），认不出也没关系，我会按音频对句子。

念错、卡壳、重念都照常留着——我要的是真实分布，不是满分。

我这边拿到后跑一条命令出报告：

```
python tools/asr211_real_mic.py --wavs <录音目录>
```

产出：判对 / 差一点 / 判错 / 空转写 计数、WER、以及「真人语音里最常整词丢掉的实词」清单。
判定用的是和 App 同一套规则（Dart 与 Python 逐条对拍钉住），所以这份报告的通过率就是引擎裁定的数。
