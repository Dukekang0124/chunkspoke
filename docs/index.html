常见问题

如何安装 APK？首次安装为何要允许“安装未知应用”？

Android 出于安全默认禁止从浏览器 / 文件管理器直接安装 APK。首次安装请：

  1. 点击「立即下载 APK」，等待下载完成；
  2. 在系统弹出的“允许安装未知应用”对话框中，为当前使用的浏览器 / 文件管理器开启“允许来自此来源的应用”；
  3. 返回继续安装即可。

此授权仅针对本次安装来源，可随时在「设置 → 应用 → 特殊应用权限 → 安装未知应用」中关闭。

是否需要联网？

不需要。APK 下载一次后，词块内容与语音识别均在设备本地完成，全程离线、免费。

支持哪些 Android 版本？

支持 Android 7.0（API 24）及以上机型。

我的学习数据会上传吗？

不会。应用不上传任何学习数据，所有进度仅保存在本机。
